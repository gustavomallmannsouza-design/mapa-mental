
# 📚 StudyHub

Projeto de um centro de materiais de estudo para estudantes que estão se preparando para o vestibular.

A proposta é reunir diferentes formatos de conteúdo em um único lugar, facilitando a organização e o acesso aos materiais.

## 🎯 Objetivo

Criar uma interface simples e organizada onde o estudante consiga encontrar rapidamente seus materiais de estudo.

Os materiais podem ser organizados por:

- PDF
- Vídeo
- Foto
- Anotação
- Matéria
- Tema

## 🖥️ Funcionalidades

### Busca

O usuário pode pesquisar materiais pelo nome.

### Filtros

É possível filtrar os conteúdos por tipo:

- Todos
- PDFs
- Vídeos
- Fotos
- Anotações

### Organização

Os materiais aparecem em cartões separados, contendo:

- Nome
- Matéria
- Tipo
- Informações do conteúdo
- Botão de acesso

### Adicionar material

O botão "Adicionar material" abre um formulário onde o usuário pode cadastrar:

- Nome do material
- Matéria
- Tipo

Após salvar, o novo material aparece automaticamente na tela.

### Responsividade

A interface foi desenvolvida para funcionar em:

- Computadores
- Tablets
- Celulares
